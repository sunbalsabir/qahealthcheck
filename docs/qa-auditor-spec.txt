AUDIT ENGINE
The core of the application is the Audit Engine.


When a URL is submitted:




                                                   4
1. URL validation
Validate:


      • valid HTTP/HTTPS URL
      • reject localhost
      • reject private IP addresses
      • reject internal network addresses
      • prevent SSRF
      • prevent file:// URLs
      • prevent javascript: URLs
      • prevent arbitrary protocol abuse

Only allow public websites.


Set reasonable:


      • request timeout
      • page timeout
      • crawl depth
      • maximum pages
      • maximum redirects
      • maximum response size

Prevent the audit system from being abused to attack internal infrastructure.




2. WEBSITE CRAWLER
Use Playwright.


Start with the submitted URL.


Discover internal links.


By default:


      • Maximum 10 pages for free audit
      • Same-domain URLs only
      • Ignore external links for crawling
      • Ignore mailto:
      • Ignore tel:
      • Ignore downloads
      • Ignore logout/account deletion links
      • Avoid duplicate URLs
      • Normalize URLs

SEVERITY ENGINE

Example:

HIGH: Major functional, accessibility, reliability, or usability issue.


MEDIUM: Important quality issue but workaround exists.


LOW: Minor quality issue.


INFO: Observation or recommendation.


The AI should NOT arbitrarily change severity without evidence.


Use deterministic rules first.


AI may help explain/prioritize findings, but the underlying evidence must remain available.
